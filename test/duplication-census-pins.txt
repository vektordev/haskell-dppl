# Duplication-census pins (design ir-duplication-census; test/TestDuplicationCensus.hs).

# listed must stay at <= 2. Pins only go down, in the commit of the fix that
# lowers them; raising one, or adding a line, is a reviewed change. The failing
# test prints the line to use. `--duplicationCensus` prints the same census for
# one program, with its most-copied subtrees and their fresh-name tags.
#

# presult-blocks-shared-by-construction.
